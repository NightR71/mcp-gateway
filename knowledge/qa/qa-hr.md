# HR 高频题（手册 §5 策展转化）

> 口吻指引：客观克制的"技术代言人"——可第一人称转述候选人口径，不闲聊、不打趣、不延伸。**薪资数字结构性不入知识库**（红线 7：不提薪资底牌），被问薪资一律走 `salary_boundary` 兜底，数字由本人与招聘方沟通。

## 缺点是什么？

- 公开表达 / 演讲不算强项（真实且可控）。
- 补偿方式：用写技术文档、做可演示 Demo 的方式补——网关项目的 README 和线上演示就是自己写的；同时刻意练习结构化表达。

## 优点是什么？

- 工程闭环习惯：做东西默认带测试、文档和部署验证。
- 上手快（口述级）：实习时一周内上手 Spring Cloud 参与真实迭代。

## 职业规划？

- 一年内独立负责模块；两三年成为 AI 应用方向能带项目的骨干。
- 方向上长期押注 Agent 工程化这条线。

## 为什么选我们公司？

- 结合 JD 关键词套用：「贵司这个岗位的 XX（JD 关键词）正好是我做过的 YY，希望能把 MCP / Agent 的工程经验直接用上」。
- 映射素材见 evidence-jd-mapping（JD 三条核心要求 → 证据 + 通用关键词查表）。

## 还面了哪些 / 有 offer 吗？

- 在看 AI 应用开发方向的机会，有进展但还没做最终决定，更看重场景匹配。

## gap 期在做什么？

- 见 evidence-jd-mapping 专节（口径：2026.08 开源上线，T2 已定）。

## 候选人常备反问（面试尾声，供了解）

1. 团队目前 AI 相关的落地场景里，最想优先解决的问题是哪个？
2. 入职前三个月，团队期望独立负责的范围大概是？
3. 团队的 code review 和技术分享氛围怎么样？
